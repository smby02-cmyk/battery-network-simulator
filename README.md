# 배터리 공급망 시뮬레이터 (Battery Network Simulator)

한누리에너지솔루션의 2026–2045년 글로벌 배터리 생산·공급 네트워크를 **비용·탄소·리드타임·20년 재무·시나리오 리스크**로 동시에 평가하는 웹 시뮬레이터입니다.

- 과제: 인천대학교 동북아물류대학원 「물류시설 설계 및 시뮬레이션」 — INU GLR Case Study 「탄소 국경 위의 배터리 공장」 (GLR-2026-BAT)
- 작성: 이승현 · 2026. 11.
- 핵심 질문: 서지원 전무의 12월 3일 이사회 권고안 — (i) 유럽 생산거점과 투자 시기, (ii) 오창·브로츠와프 역할, (iii) 2035년 고객별 공급 비중, (iv) 탄소 산정 규칙 변화 헤지, (v) 점검 지표와 전환 조건

## 결론 한 줄

**규제가 오든 안 오든 유럽 시장을 지키려면, 데브레첸(헝가리)을 단계적으로 짓고 브로츠와프(폴란드) 탈탄소화를 준비해야 한다. 브로츠와프 증설은 기각한다.**

| 구분 | ver1: 규제 미시행 | ver2: 규제 시행 |
| --- | --- | --- |
| 의미 | 시장기반 탄소 산정(PPA·GO 인정) 유지 | 위치기반 산정 + 탄소발자국 상한(2030년 65kg, 2035년 60kg/kWh) |
| 기존 네트워크 20년 NPV | 159.6억 달러 | 61.1억 달러 (유럽 공급 0) |
| 데브레첸 증분 NPV | +2.6억 달러 | +23.4억 달러 |
| 브로츠와프 증설 증분 NPV | −3.7억 달러 | −36.8억 달러 |
| 브로츠와프 탈탄소화 35% 가치 | 0 | 최대 95.4억 달러 (비용 전) |

자세한 분석은 [`docs/`](docs) 폴더의 Q1~Q6 문서를 참고하세요.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

회귀 테스트 (케이스 수치 48개 재현 확인, 약 20초):

```bash
python tests/test_regression.py
```

## 주요 가정

- 고객 이원화: OEM 거점별 수요의 최대 70%까지 수주, 생산능력 부족분은 벌금 없이 미공급 (보수적 평가)
- ver2 상한 판정: 위치기반 탄소발자국 + 고객까지 운송배출, 고객별 판정
- 직접 연결 저탄소 전력(자가발전·전용선)은 위치기반에서도 인정된다고 가정
- 탈탄소화 투자비는 케이스에 없어 NPV에서 빼지 않고 "최대 지불 가능액(손익분기)"으로 제시
- 법인세는 공장별 과세, 적자 연도 세금 0
