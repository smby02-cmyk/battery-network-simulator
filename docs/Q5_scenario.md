## 0. 보고 프레임

| 구분 | 의미 |
| --- | --- |
| **ver1: 규제 미시행** | 시장기반 탄소 산정 유지, 이익 기준 공급 (자료 14 '기준') |
| **ver2: 규제 시행** | 위치기반 산정 + 탄소발자국 상한(2030년 65kg, 2035년 60kg), 상한 초과 공장 유럽 공급 불가 (자료 14 '탄소발자국 상한') |

프로젝트의 3대 핵심 축과 시나리오 5개의 대응:

| 핵심 축 | 시나리오 | 시험 내용 |
| --- | --- | --- |
| ① 탄소 규제 리스크 | 기준(ver1) ↔ 상한(ver2) — 주 축 | 규제가 시장 접근을 막을 때 |
| | 고탄소 | 규제가 비용을 올릴 때 (탄소가격 ×1.5, 2030년부터 한국산 CBAM 100%, OEM 내부 탄소가격) |
| | 역내생산 요건 | 정책이 한국산에 불이익을 줄 때 (2030년부터 kWh당 6달러) |
| ② 유럽 물량 공급 | 기준 ↔ 수요 둔화 | 수요가 예상보다 적을 때 (성장률 ×0.5) |
| ③ 수익성 | 모든 시나리오의 네트워크 증분 NPV | 각 경우에 돈이 되는가 |

**본문 메시지 방식(확정):** 확률을 직접 넣지 않고 ① "강한 규제(ver2) 확률 p에 대한 손익분기"와 ② "어떤 확률에서도 결론 불변"으로 제시한다. 확률 가정 3종(균등·규제 중시·수요 우려)은 부록 민감도로 둔다.

## 1. 질문

- (a) 각 시나리오의 발생 확률을 스스로 정하고 기대 NPV를 계산하라.
- (b) 최대 후회(maximum regret)를 최소화하는 대안을 찾아라. 두 기준의 답이 다르다면 그 이유는?
- (c) 헝가리의 정치 리스크, 사라고사의 중국 합작공장, 노스볼트의 교훈처럼 모형 밖에 있는 위험을 판단에 어떻게 반영하겠는가?
- (d) 지금 투자를 확정하는 것과 2028년까지 결정을 미루는 것의 득실을 비교하라.

## 2. 적용 이론

| 개념 | 내용 |
| --- | --- |
| 시나리오 계획 | 하나의 예측 대신 여러 미래를 정의하고 각 미래에서 대안을 평가 |
| 기대값 기준 | Σ 확률 × 결과. 확률 추정에 의존 |
| 최대후회 최소화 (minimax regret) | 각 시나리오의 "최선안 대비 손해" 중 최댓값이 가장 작은 대안. 확률 불필요 |
| 실물옵션 | 투자를 미루거나(지연) 나눠서(단계) 하는 권리의 가치. 정보를 얻은 뒤 결정할 수 있음 |
| 효율성 vs 회복탄력성 | 단일 시나리오 최적안보다 여러 미래에서 버티는 안을 선택 |

출처: 케이스 연결표(25쪽), SCM 3강 공급망 전략, NET 6장 투자 타당성(민감도)

## 3. 재무 모듈 확장과 검증

- 추가 시나리오: 고탄소, 수요 둔화, 역내생산 요건
- 고탄소의 OEM 내부 탄소가격: (시장기반 탄소발자국 + 운송배출 − 50kg) × 탄소가격, **양방향** (50kg 초과는 가격 차감, 미달은 가산). 자료 14 "50kg/kWh 초과분(미달분)" 문구 기준
- 실물옵션: 신규 공장 투자 지연(년), 브로츠와프 탈탄소화 시작 연도
- **검증:** 후보지 8곳 × 시나리오 5개 = 40개 증분 NPV가 자료 14와 백만 달러 단위까지 일치. 기존 네트워크 NPV는 0.1~0.4% 이내

## 5. 해석

1. **데브레첸은 확률과 무관하게 최선이다.** 수요 둔화를 뺀 4개 시나리오에서 양(+)이고, 기대값·최대후회 모두 1위.
2. **유일한 약점은 수요 둔화(−12.1억 달러)이며, 실물옵션(단계적 확정)으로 대응한다.**
3. **브로츠와프 증설은 모든 시나리오에서 음(−)이다.**
4. **브로츠와프 탈탄소화는 ver2 보험이며 시점이 중요하다.** 2년 늦을 때마다 ver2 가치가 17~20억 달러 줄어든다. 위임법 확정 후 착수하더라도 준비는 지금 해야 2030년에 맞출 수 있다.
5. **두 번째 공장은 ver2가 매우 확실할 때(p > 83%)만 가치가 있다.**

## 6. 결론 (확정)

1. **데브레첸(헝가리): 단계적 확정**
   - 1단계(지금~2027년 초): 고객 입찰에 대응 가능한 수준으로 준비. 부지 확보, 인허가, 보조금 협상, 전력·용수 계약, 고객사 G 탄소 자료 제출(시장기반·위치기반 모두)과 2030년 플랫폼 입찰 대응.
   - 2단계(2027년 초 착공 결정): 수요 지표, 수주 결과, 헝가리 정책을 확인하고 본격적인 손익을 다시 따져 본투자 확정.
   - 이유: 입찰 기회를 지키면서 수요 둔화 리스크(−12.1억$)를 피할 수 있다.
2. **브로츠와프 증설(폴란드): 기각.** 모든 시나리오에서 음(−).
3. **브로츠와프 탈탄소화(폴란드):** 비용 견적 < 95.4억$ × p 이면 실행. 직접 연결 저탄소 전력 타당성 검토와 계약 준비는 지금 시작하고, 위임법이 위치기반으로 확정되면 즉시 착수(2030년 상한 시점에 맞춤).
4. **두 번째 신규 공장: 보류.** ver2 확률이 80%를 넘거나, 위임법 확정 후 브로츠와프 탈탄소화가 불가능할 때 재검토. 후보 순위는 사라고사(스페인) → 오스트라바(체코) → 두브랭(프랑스) (ver2 증분 NPV 순).

→ 권고안 (i) 투자 대안과 시기, (iv) 탄소 헤지, (v) 전환 조건
